# Home Page Redesign Prompt

Update the existing **Home Page** using the current website as the foundation.

Use the **DigitalOcean AI-Native Cloud homepage** as a structural/reference example, but **do not copy its branding, colors, typography, or exact design**.

Reference: DigitalOcean AI-Native Cloud homepage.

## Critical Rule

**Do NOT change the existing website's visual identity.**

Keep:

* Existing colors
* Existing typography
* Existing buttons
* Existing spacing style
* Existing navbar
* Existing backgrounds
* Existing borders
* Existing animations
* Existing overall design language

The new sections must feel like they were naturally designed as part of the existing website.

The final result should remain **clean, minimal, professional, corporate, and plain**.

---

## 1. Existing Hero / Intro

Keep the existing Home Page hero/intro section exactly as it is.

Do not redesign or replace the existing intro.

Immediately **below the intro section**, add the new marquee section.

If the existing website already has suitable company/logo assets, reuse those where appropriate.

## 5. Visual Design

The entire new content must inherit the **existing website's design system**.

Do NOT introduce:

* New color palettes
* Neon effects
* Excessive gradients
* Unnecessary glassmorphism
* Excessive shadows
* Cartoon-style graphics
* Excessive rounded cards
* Overly complex animations

The design should communicate:

**Professional · Corporate · Reliable · Modern · Clean · Minimal**

The reference website is being used only for **layout inspiration and information hierarchy**, not for visual copying.

---

## 6. Responsive Design

Make all new sections responsive.

### Desktop

* Marquee spans the page naturally.
* Three giant blocks appear side-by-side.
* Five layers use a horizontal/tab-style layout.

### Tablet

* Adjust spacing and typography.
* Preserve the visual hierarchy.

### Mobile

* Three blocks stack vertically.
* Five layers become a mobile-friendly vertical or horizontally scrollable selector.
* Marquee remains smooth and does not cause horizontal page overflow.
* All text remains readable.

---

## 7. Implementation Rules

Before making changes:

1. Inspect the existing Home Page.
2. Understand the current component structure.
3. Identify the existing styling system.
4. Reuse existing components/classes/styles wherever possible.
5. Do not rewrite unrelated parts of the website.
6. Do not change the navbar.
7. Do not change the existing hero/intro design.
8. Do not change existing colors or branding.

Only add the requested sections.

Keep the code clean, reusable, and component-based where the existing project architecture supports it.
